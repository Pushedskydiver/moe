**Novel patterns this session:**

1. **Fixing a review finding can uncover — or itself introduce — the next gap in the same call chain, repeatedly.** Three consecutive rounds (R1→R2→R3) each found the previous commit's fix only partially closed the underlying "malformed/adversarial `DATABASE_URL` crashes or leaks" class, via a different specific code path each time (a bare `new URL()`, then `decodeURIComponent`, then an un-escaped control character in the generated env file). The lesson isn't "the fixes were bad" — each one genuinely closed what it targeted — it's that a security-sensitive function accepting untrusted input deserves one adversarial-input-enumeration pass up front (or a fresh reviewer explicitly told to hunt broadly, not just verify the stated claim) rather than fixing exactly the reported symptom each round and hoping nothing adjacent got missed.
2. **A background review-agent dispatch can fail on pure infrastructure, not agent judgment — retry before assuming the task itself is unworkable.** The fourth-round verification dispatch hit "Connection closed mid-response" three times in a row via the plain Agent tool, then hung entirely when tried via the Workflow tool. What actually worked was narrowing the prompt from open-ended ("hunt broadly for a fourth category of bug") to a fixed 4-step numbered checklist — worth trying a tighter scope before concluding a dispatch is structurally too heavy, but also worth just retrying 2-3 times first since this looked like transient infra flakiness, not a scope problem, until the narrower prompt actually confirmed it.
3. **A review agent's own self-imposed scope ceiling firing is a signal to work with, not around.** `copilot-surrogate`'s 20-file cap correctly fired on this PR's real 28-file diff and returned a well-reasoned narrower recommendation (the 7 files actually carrying external/cross-doc claims) rather than either silently truncating or refusing outright — re-dispatching on exactly that recommended scope was the right move, not overriding the ceiling.
